# 🌸 Wonder Bubble Studio

ระบบจัดการร้านเติมเกม Robux ID-PASS · ตัดสต็อกเมล USD อัตโนมัติ · คำนวณกำไรทันที

---

## ⚠️ อ่านก่อนเป็นอันดับแรก — ตั้งค่า Postgres บน Railway

ตอนนี้เซิร์ฟเวอร์รันด้วย **file storage** (`/api/version` ตอบ `"storage": "file"`)

**Railway ล้างไฟล์ในคอนเทนเนอร์ทุกครั้งที่ deploy** แปลว่าออเดอร์ทุกใบที่บันทึกหลังจาก
commit ล่าสุดจะหายไปทันทีที่ deploy ครั้งถัดไป (เคยเกิดมาแล้วเมื่อ 30 ส.ค. 2026)

**วิธีแก้ (ทำครั้งเดียวจบ):**

1. เปิดโปรเจกต์บน Railway → **New** → **Database** → **Add PostgreSQL**
2. ไปที่ service ของเว็บ → **Variables** → เพิ่มตัวแปร
   `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
3. Deploy ใหม่ แล้วเช็กว่า `/api/version` ตอบ `"storage": "postgres"`

ครั้งแรกที่บูตกับฐานข้อมูลว่าง ระบบจะย้ายข้อมูลจาก `data/shop_data.json` เข้า Postgres
ให้เอง หลังจากนั้นไฟล์นี้เป็นแค่ seed สำรอง ไม่ได้ใช้เก็บของจริงอีก

> 💾 **ก่อน deploy ทุกครั้ง** โหลดสำรองไว้ก่อน:
> `https://<โดเมนของคุณ>/api/backup`

## ✨ ความสามารถ

- **บันทึกการเติม 1 คลิก** — กรอก Username → เลือกแพ็กเกจ → ระบบบอกวิธีกดในเกมตัวโต ๆ
  เลือกเมลที่ตัด คำนวณต้นทุน/กำไร/มาร์จิ้นสด ๆ และหักเครดิต USD ให้เอง
- **กันเครดิตติดลบ** — เตือนก่อนถ้าเมลที่เลือกมีเครดิตไม่พอ
- **ประวัติออเดอร์** — กรองตามช่วงวัน (วันนี้ / เมื่อวาน / 7 วัน / เดือนนี้ / เดือนที่แล้ว /
  เลือกวันเอง) ค้นหาได้ทุกช่อง และ**แก้ไขได้ทุกฟิลด์ รวมถึงวันที่และเวลา**
- **ตรวจสุขภาพข้อมูล** — ชี้ออเดอร์ที่ลงวันที่ล่วงหน้า เลขออเดอร์ซ้ำ เมลที่หายไปจากระบบ
  และเมลที่เครดิตติดลบ พร้อมปุ่มกดดูรายการนั้นทันที
- **สต็อกเมล** — หลอดพลังเครดิต มูลค่าคงเหลือเป็นบาท กำไรสะสมรายเมล เปิด/ปิดได้ทุกเครื่องพร้อมกัน
- **ตารางราคา** — ใส่เรทเพื่อจำลองต้นทุนและกำไรของทุกแพ็กเกจ
- **สรุปภาพรวม** — KPI ตามช่วงเวลา กราฟยอดขายรายวัน แพ็กเกจขายดี ผลงานพนักงาน
- **ส่งออก** — CSV (UTF-8 BOM เปิดใน Excel ภาษาไทยได้เลย) และ Backup JSON ทั้งระบบ
- **ซิงก์สด** — SSE + WebSocket + poll สำรอง ทำงานต่อได้แม้เน็ตหลุด แล้วส่งขึ้นให้เองเมื่อกลับมา

## 🚀 การใช้งาน

### รันเป็นเซิร์ฟเวอร์ (ใช้จริงในร้าน — แนะนำ)

```bash
npm install
npm start
```

เปิด <http://localhost:3000> ทุกเครื่องที่เปิดหน้านี้จะเห็นข้อมูลตรงกันแบบเรียลไทม์

### เปิดไฟล์ตรง ๆ

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย จะเข้าโหมด **ในเครื่อง** — ใช้ราคา พนักงาน
และรายชื่อเมลจาก `assets/seed.js` เก็บออเดอร์ไว้ใน localStorage และไม่ซิงก์กับใคร

## 📁 โครงสร้างไฟล์

```
index.html          โครงหน้าเว็บ
assets/app.css      ดีไซน์ทั้งหมด (เขียนเอง ไม่พึ่ง CDN ภายนอก)
assets/app.js       ตรรกะฝั่งผู้ใช้ทั้งหมด
assets/seed.js      ข้อมูลตั้งต้นสำหรับโหมดออฟไลน์ (สร้างจาก tools/make-seed.js)
server.js           API + WebSocket + SSE + การเก็บข้อมูล
data/shop_data.json seed สำหรับบูตครั้งแรก / ที่เก็บสำรองเมื่อไม่มี Postgres
tools/make-seed.js  สร้าง assets/seed.js ใหม่
```

สร้าง seed ใหม่หลังแก้ราคาหรือรายชื่อเมล:

```bash
node tools/make-seed.js
```
