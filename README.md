# 🌸 Cozy Robux Studio (Wonder Bubble Stock)

ระบบจัดการร้านเติมเกม Robux ID-PASS, ตัดสต็อกเมล USD อัจฉริยะ, และคำนวณกำไรอัตโนมัติ สไตล์มินิมอลพาสเทลลาเวนเดอร์ ใช้งานง่ายในไม่กี่คลิก

## ✨ คุณสมบัติเด่น (Features)

- **⚡ บันทึกการเติมเงิน 1-Click (Direct Cashier):**
  - กรอก Username ลูกค้า ➔ เลือกแพ็กเกจ Robux (80R - 20,000R)
  - ระบบแสดงวิธีกดในเกม + เลือกเมลสต็อกที่เรทดีที่สุดให้อัตโนมัติ
  - คำนวณต้นทุน, กำไรสุทธิ, และมาร์จิ้น % แบบ Real-time
  - กด "บันทึกการเติมสำเร็จ" ปุ่มเดียวจบ พร้อมหักเครดิต USD อัตโนมัติ

- **📦 จัดการสต็อกเมล & เครดิต USD (Mail Stocks):**
  - แสดงสถานะสต็อกเมล (`PC-001` ถึง `PC-009`...) พร้อมหลอดพลัง (Progress Bar)
  - คำนวณมูลค่าคงเหลือ (บาท) และกำไรสะสมที่แต่ละเมลสร้างได้
  - ระบบคืนเครดิตอัตโนมัติเมื่อมีการลบหรือแก้ไขออเดอร์

- **🔍 ระบบค้นหาคิวย้อนหลังทันใจ (Instant Search & Pagination):**
  - ค้นหาได้ทั้ง Username, Order ID, รหัสเมล, หรือชื่อพนักงาน
  - โหลดเร็ว ลื่นไหล ไม่หน่วง ด้วยระบบแบ่งหน้า

- **🏷️ ตารางราคา & จำลองเรทกำไร (Pricing Simulator):**
  - กรอกเรทแลกเปลี่ยนเพื่อดูต้นทุนและกำไรล่วงหน้าได้ทันที

- **📊 สรุปยอดขาย & ส่งออก (Dashboard & Export):**
  - สรุปยอดขายและกำไรวันนี้ แยกตามรายชื่อพนักงาน
  - ดาวน์โหลดรายงานเป็นไฟล์ **Excel (CSV)** (รองรับภาษาไทย 100% ด้วย UTF-8 BOM)
  - ดาวน์โหลด Backup ทั้งระบบเป็นไฟล์ **JSON**

## 🚀 วิธีเปิดใช้งาน (Getting Started)

### 1. ใช้งานผ่าน Web Browser ทันที
เพียงเปิดไฟล์ `index.html` บน Google Chrome, Microsoft Edge, หรือ Safari ก็สามารถใช้งานได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์เพิ่มเติม

### 2. เผยแพร่ผ่าน GitHub Pages
1. ไปที่แท็บ **Settings** ของ Repository บน GitHub
2. เลือกเมนู **Pages** ทางด้านซ้าย
3. ในส่วน **Build and deployment > Branch** ให้เลือก Branch `main` แล้วกด **Save**
4. ระบบจะสร้างลิงก์เว็บไซต์ออนไลน์ให้เปิดใช้งานได้ทุกที่ทุกเวลา!
